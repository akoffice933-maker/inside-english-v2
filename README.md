# Inside English v2.0 — Архитектура, База Данных и Интерактивный Прототип

Приветствуем! Предоставленное вами Техническое Задание (ТЗ) — это шедевр продуктового проектирования. Сочетание языковой практики с психологическим комфортом, концепцией **Inside**, картой состояний и глубоким погружением через MindTracks / ГипноТреки действительно переводит продукт в премиум-сегмент с высоким LTV.

Мы детально проанализировали ТЗ, спроектировали структуру базы данных PostgreSQL, подготовили стартовый набор данных и создали **полноценный интерактивный React-компонент** плеера и панели управления, полностью соответствующий вашему дизайн-гайду.

## 📂 Что было создано в вашем рабочем пространстве:

1. **`schema.sql`** — Полный SQL-скрипт структуры базы данных для Supabase (PostgreSQL). Включает в себя:
   * Кастомные типы перечислений (`user_level`, `track_type`, `emotional_state`, `word_status`).
   * Включение расширения `uuid-ossp` для генерации ID.
   * Настройку Row-Level Security (RLS) политик безопасности для всех таблиц (пользователь видит только свои данные, а треки доступны авторизованным пользователям).
   * Автоматический триггер обновления времени изменения записей (`updated_at`).
   * Производительные индексы на часто фильтруемые поля (`state`, `level`).
2. **`seed_data.json`** — Файл инициализации контента, содержащий прототипы MindTrack и Гипно-трека с точной структурой токенов (таймкоды начала и конца, русские, английские и смешанные билингвальные фразы с HTML-подсветкой акцентов в стиле Inside).
3. **`components/InsideAppPreview.tsx`** — Интерактивный TypeScript React-компонент, реализующий:
   * **Экран "Главная"**: приветствие, селектор состояний (🧘/⚡/🌙), списки треков.
   * **Экран "Сеансы"**: фильтрация и списки в стиле Apple Podcasts.
   * **Экран "Профиль"**: счетчики дней, времени практики и **визуализация "Колеса Баланса"** на базе динамического SVG.
   * **Продвинутый плеер (Player Screen)**:
     * Таймер воспроизведения с синхронизацией предложений по таймкодам.
     * Мгновенное переключение режимов текста: *Русский*, *Смешанный* (с акцентом на английские фразы фиолетовым цветом `#7B61FF`), *English Only*.
     * Изменение скорости (1.0x, 1.2x, 1.5x).
     * Режим Shadowing: интерактивный микрофон с анимацией звуковой волны и мгновенной симуляцией оценки произношения по каждому слову (зеленый/желтый/красный).
     * Опрос о самочувствии по завершении гипно-трека.

## ⚡ Экспертный разбор архитектуры и технические рекомендации:

### 1. Как устроена синхронизация текста и звука?
В `seed_data.json` мы заложили массив `tokens`. Каждый элемент — это предложение или слово с четкими границами времени:
```json
{
  "id": 1,
  "start": 0.0,
  "end": 3.5,
  "russian": "Сегодня я проснулся рано.",
  "english": "Today I woke up early.",
  "mixed": "Сегодня я проснулся <span class='text-[#7B61FF] font-medium'>early</span>."
}
```
**На фронтенде** (что реализовано в `InsideAppPreview.tsx`), плеер непрерывно отслеживает `currentTime`. Текст рендерится с динамическими классами прозрачности:
* `currentTime < token.start` ➡️ Будущий текст: opacity-20 (полупрозрачный).
* `currentTime >= token.start && currentTime <= token.end` ➡️ Текущий активный текст: белый цвет (opacity-100), легкое масштабирование, фокус внимания.
* `currentTime > token.end` ➡️ Прочитанный текст: opacity-50.

### 2. Поддержка фонового режима на iOS/Android (PWA)
Для того чтобы гипно-треки и MindTracks продолжали воспроизводиться при заблокированном экране телефона или в свернутом браузере, необходимо использовать **Media Session API**:
```javascript
if ('mediaSession' in navigator) {
  navigator.mediaSession.metadata = new MediaMetadata({
    title: activeTrack.title,
    artist: 'Inside English',
    album: 'Immersion Practice',
    artwork: [
      { src: '/images/inside-logo-512.png', sizes: '512x512', type: 'image/png' }
    ]
  });

  navigator.mediaSession.setActionHandler('play', () => audioRef.current.play());
  navigator.mediaSession.setActionHandler('pause', () => audioRef.current.pause());
}
```
Это позволит пользователю управлять медиа-контентом прямо с экрана блокировки смартфона или через смарт-часы.

### 3. Специфика записи звука (Shadowing) в Safari на iOS
Браузер Safari на мобильных устройствах iOS имеет жесткие ограничения на аудиокодеки. 
* Стандартный `MediaRecorder` на Android записывает в `audio/webm`.
* iOS Safari требует записи в контейнер `audio/mp4` или `audio/aac`.
* **Решение:** В коде инициализации записи голоса необходимо динамически проверять поддерживаемые форматы:
  ```javascript
  let options = {};
  if (MediaRecorder.isTypeSupported('audio/webm;codecs=opus')) {
    options = { mimeType: 'audio/webm;codecs=opus' };
  } else if (MediaRecorder.isTypeSupported('audio/mp4')) {
    options = { mimeType: 'audio/mp4' };
  }
  ```

### 4. Интеграция Whisper API для Shadowing (Спринт 4)
Когда пользователь отправляет записанный аудиофайл (multipart/form-data) на бэкенд (Edge-функция Supabase):
1. Аудио передается в Whisper API с параметром `word_timestamps=true`.
2. Мы получаем точные таймкоды распознанных слов и сравниваем их с исходным текстом предложения.
3. Для сравнения текстов на сервере используется расстояние Левенштейна или косинусное сходство векторных представлений слов. Результатом является массив объектов, как в нашем демонстрационном UI:
   ```json
   "words": [
     { "word": "Today", "status": "match" },
     { "word": "I", "status": "match" },
     { "word": "woke", "status": "match" },
     { "word": "up", "status": "warn" },
     { "word": "early", "status": "match" }
   ]
   ```

## 🚀 Как развернуть и протестировать прототип

### Шаг 1. База данных
Скопируйте содержимое файла `schema.sql` и выполните его в **SQL Editor** в вашей панели управления **Supabase**. Все таблицы, индексы и политики безопасности будут мгновенно настроены.

### Шаг 2. Разметка интерфейса
Компонент `components/InsideAppPreview.tsx` полностью самодостаточен и написан на TypeScript. Он использует стандартный Tailwind CSS. 
Вы можете скопировать его в свой проект Next.js (например, в директорию `src/components/` или `components/`) и импортировать в любую страницу. 
*Для работы вам потребуется установить набор иконок (или использовать SVG-заглушки, встроенные в прототип).*
