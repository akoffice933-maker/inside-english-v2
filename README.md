# Inside English v2.0 — Премиальная экосистема изучения языков и осознанности
**Стек проекта:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Zustand, Framer Motion, CapacitorJS v5, Telegram WebApp SDK, Supabase (PostgreSQL), OpenAI API (Whisper v1 + GPT-4o).

Добро пожаловать в репозиторий **Inside English v2.0** (также известного как **Flow Talk / Inside Bridge**) — высокотехнологичного премиум-продукта, который переопределяет нишу языкового обучения, объединяя эффективную практику общения с психологическим комфортом и осознанностью (mindfulness).

Приложение спроектировано для кросс-платформенного деплоя из единого монорепозитория в три целевые среды: **Web PWA**, нативное **iOS-приложение** (для публикации в App Store через Capacitor) и **Telegram Mini App (TMA)**.

## 🚀 Ключевые возможности и ИИ-функции

### 1. Inside Bridge (Flow Talk) — Умный ИИ-посредник в разговоре
Инструмент для снятия языкового барьера во время реальных телефонных разговоров по схеме **«Спикерфон + Приложение» (MVP)**:
*   **Голосовой конвейер (Voice Loop):** Микрофон смартфона захватывает реплики собеседника со спикерфона чанками по 4-5 секунд, транскрибирует их через Whisper API с автоматическим определением языка и передает в семантическое ядро GPT-4o.
*   **Анализ намерений (Intent & Tone):** ИИ за доли секунды определяет буквальный перевод реплики, скрытые намерения говорящего (например, «Вежливый отказ», «Согласие») и его эмоциональный тон (например, «Неуверенность», «Спешка»).
*   **Интерфейс «Тихих подсказок» (Quiet Hints):** ИИ генерирует 3 ультра-коротких варианта ответа в одну строку. Кнопки ответов имеют крупный шрифт для быстрого считывания боковым зрением и сопровождаются нативными Haptic-вибрациями смартфона при обновлении.
*   **Кнопка экстренной помощи (SOS):** Пользователь наговаривает реплику на русском ➡️ ИИ формулирует её в идеальный грамматический английский и озвучивает собеседнику.

### 2. ИИ-Коуч Состояния (AI Mood Coach)
Гипер-персонализация обучения на основе эмоционального чек-ина:
*   Пользователь описывает свое текущее самочувствие ➡️ ИИ-Коуч генерирует индивидуальное напутствие (Intro) и уникальную дневную аффирмацию (EN).
*   Аффирмация преобразуется в пословные таймкоды (`tokens`), автоматически загружается в плеер и начинает проигрываться с синхронной подсветкой слов под расслабляющий фоновый звук.

### 3. Двухрежимный аудиоплеер (Zustand + HTML5 Audio)
*   **Свернутый мини-бар:** Парит над нижним меню, позволяя продолжать навигацию по приложению во время прослушивания уроков.
*   **Развернутый плеер (Lyrics Sync):** Отображает текст, плавно подсвечивая активные слова неоновым свечением `.text-glow-purple` ровно в ту секунду, когда их произносит диктор.
*   **Трехрежимный переключатель языка:** Мгновенное переключение текста (*Русский / Смешанный с фиолетовыми RU-EN акцентами / English Only*) без прерывания звука.

## 🔒 2. Архитектура безопасности и защита контента

Проект прошел жесткий ручной технический аудит. Все критические уязвимости закрыты на уровне кода:

1.  **Защита платных текстов в СУБД:**  
    Текстовые сценарии и tokens полностью удалены из таблицы `tracks` (доступной всем пользователям) и вынесены в изолированную таблицу `track_contents`. Доступ к строкам tokens защищен RLS-политикой на уровне PostgreSQL — база возвращает tokens только если трек бесплатный или если у пользователя активен флаг `settings->>'is_premium' = true`.
2.  **Защита Webhook Telegram Stars от фальсификации:**  
    Эндпоинт приема платежей `/api/telegram/webhook` защищен обязательной сверкой заголовка `X-Telegram-Bot-Api-Secret-Token` с системной переменной в безопасном по времени режиме буферов с помощью `crypto.timingSafeEqual` (противодействие Timing-атакам). Подделать успешный платеж, зная UUID пользователя, невозможно.
3.  **Защита ИИ-роутов от спама и разорения баланса (Rate Limiting):**  
    Создан скользящий лимитер запросов (Sliding Window) с автоматическим Garbage Collector'ом для очистки локальной памяти `Map` каждые 5 минут. Эндпоинты `/api/ai/coach/check-in`, `/api/bridge/voice/process` и `/api/bridge/message/send` строго закрыты проверкой `is_premium` в продакшене. Дополнительно установлены лимиты по IP (5/мин на авторизацию, 10/мин на shadowing).
4.  **Защита от Replay-атак в Telegram Auth:**  
    Роут `/api/auth/telegram` проверяет параметр времени подписи `auth_date`. Запросы, подписанные серверами Telegram более 24 часов назад, отклоняются.

## 💳 3. Двухканальная система монетизации (IAP vs Stars)

Приложение реализует гибкий дуальный биллинг для соответствия гайдлайнам Apple App Store и правилам Telegram Bot API:

*   **iOS-сценарий (RevenueCat):** При запуске на мобильном устройстве (внутри Capacitor) SubscriptionPage инициализирует синглтон `Purchases.configure()` и проводит платеж через StoreKit Apple. Вебхук RevenueCat принимает уведомления об оплатах по UUID пользователя.
*   **Telegram-сценарий (Telegram Stars):** Внутри Mini App тарифная сетка автоматически переключается на **Telegram Stars (Звёзды)** (`150 🌟` и `750 🌟`). Оплата инициирует создание инвойса через Bot API и открывает нативное окно `openInvoice`.
*   **Мост Идентификации (ID Bridge):** Вебхук Telegram ищет пользователей по их Telegram ID через сервисный email-генератор `tg_{telegramId}@inside-english.telegram`, а классический вебхук RevenueCat ищет по Supabase UUID, что гарантирует точное начисление премиума в обоих мирах.

## ⚙️ 4. Двойная система компиляции (SSR vs Static)

Конфигурация `next.config.js` динамически адаптируется под среду развертывания:
*   **Default SSR (Vercel / Docker):** Собирает полноценное серверное приложение. Middleware, API-роуты и защита от спама компилируются в боевом режиме.
*   **Static SPA (Capacitor / GitHub Pages):** При сборке с переменной среды `NEXT_OUTPUT_EXPORT=true` Next.js переходит в статический экспорт (`output: 'export'`). 

Для удобства команды вынесены в `package.json`:
*   `npm run build` ➡️ Сборка серверного SSR-приложения.
*   `npm run export` ➡️ Статическая сборка (скрипт временно убирает `/api` за рамки папки `/app` во избежание ошибок статического пререндеринга, экспортирует SPA в `/out` и возвращает `/api` на место).

## 🏁 5. Инструкция по локальному запуску и деплою в продакшн

### Локальная настройка:
1.  Клонируйте репозиторий и установите зависимости:
    ```bash
    git clone https://github.com/akoffice933-maker/inside-english-v2.git
    cd inside-english-v2
    npm install
    ```
2.  Скопируйте `.env.example` в `.env.local` и пропишите ваши ключи.
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```

### Деплой СУБД (Supabase):
1.  Перейдите в консоль Supabase SQL Editor.
2.  Поочередно примените файлы миграций из корня проекта:
    *   `schema.sql` (Основные таблицы, индексы, RLS).
    *   `push_tokens_migration.sql` (Хранение токенов устройств).
    *   `storage_policies.sql` (Политики приватных бакетов медиафайлов).
    *   `supabase_migrations.sql` (Таблицы ИИ-Коучинга и сессий Inside Bridge).

### Регистрация Вебхука Telegram (Разовый шаг в проде):
Сразу после деплоя Next.js на хостинг, выполните в браузере GET-запрос для регистрации вебхука вашего бота с секретным токеном:
```
https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook?url=https://<ВАШ_ДОМЕН>/api/telegram/webhook&secret_token=<ВАШ_СЕКРЕТНЫЙ_ТОКЕН>
```
*Не забудьте прописать `<ВАШ_СЕКРЕТНЫЙ_ТОКЕН>` в переменную `TELEGRAM_WEBHOOK_SECRET_TOKEN` на вашем хостинге!*
