# План внедрения «Inside Bridge» (Flow Talk) MVP: Режим «Спикерфон» и «Тихие подсказки»
**Роль:** Chief Technology Officer (CTO) / Lead Product Architect  

Режим **«Спикерфон + приложение»** — это единственно верный, стратегически выигрышный путь для запуска MVP. Он обходит жесткие ограничения Apple iOS на запись звонков из коробки (CallKit не разрешает записывать аудио обычных сотовых звонков по соображениям конфиденциальности), не требует сложных SIP/VoIP интеграций и готов к запуску прямо сейчас.

Ниже представлен детальный план реализации голосового цикла, спецификации интерфейса «Тихих подсказок» (Quiet Hints) и готовый код бэкенд-маршрута обработки аудиопотока.

---

## 🗺️ ЭТАП 1. Архитектура голосового цикла (Voice Loop Pipeline)

```
[Разговор на громкой связи] 
       │
       ▼ (Запись чанками по 4-5 секунд при наличии голоса - VAD)
[Браузерный рекордер на клиенте]
       │
       ▼ (Формат FormData: audio, sessionId)
[POST /api/bridge/voice/process]
       │
       ├──► 1. Отправка в OpenAI Whisper API (Транскрипт)
       ├──► 2. Локальный вызов ИИ-движка GPT-4o (Intent, Emotion, 3 Replies)
       │
       ▼ (Ответ с задержкой < 1.5 сек благодаря in-memory конвейеру)
[Рендеринг карточки «Тихой подсказки» на экране телефона]
```

*Для минимизации задержек мы объединили транскрибацию Whisper и семантический разбор GPT-4o в рамках одного инлайнового серверного запроса. Это экономит до 1.2 секунды на лишних сетевых запросах.*

## 🎨 ЭТАП 2. Дизайн-гайдлайны интерфейса «Тихих подсказок» (Quiet Hints)

Чтобы интерфейс не отвлекал во время напряженного звонка, разработчики должны строго придерживаться следующих UX/UI правил:

1.  **Правило 1 строки (Ultra-minimalism):**  
    Каждая из 3 подсказок-ответов на экране должна занимать ровно одну строку. Никаких длинных абзацев. Крупный шрифт (`font-size: 16px`), полужирное начертание для легкого считывания боковым зрением.
2.  **Тактильное информирование (Haptic Notification):**  
    В момент, когда ИИ распознал новую реплику и сгенерировал свежие подсказки, телефон отправляет легкий, но ощутимый виброотклик `success`. Пользователь понимает, что на экране обновился текст, даже не глядя на дисплей непрерывно.
3.  **Принцип инкогнито (Privacy by Design):**  
    В настройках сессии должен быть тумблер **«Режим Инкогнито»**. При его включении аудиозаписи и реплики обрабатываются только в оперативной памяти (транзитно) и **никогда не записываются в базу данных**. Это защищает пользователя юридически и повышает доверие.

## 📅 ЭТАП 3. 2-недельный Спринт-план реализации MVP

### 🗓️ Спринт 1.1: Голосовой API-конвейер (Бэкенд) — 4 дня
*   **Задача 1:** Развернуть роут `/api/bridge/voice/process` (код ниже) для потокового приема аудиозаписей.
*   **Задача 2:** Настроить промпты GPT-4o на генерацию сверхкоротких («тихих») вариантов ответов под 4 контекста («Работа», «Сервис», «Знакомство», «Свободный разговор»).
*   **Задача 3:** Написать SQL-миграцию для добавления флага `incognito_mode BOOLEAN` в сессии.

### 🗓️ Спринт 1.2: Клиентский интерфейс «Bridge Workspace» (Фронтенд) — 6 дней
*   **Задача 1:** Написать React-компонент `BridgeWorkspace.tsx` с разделенным экраном и крупным шрифтом подсказок.
*   **Задача 2:** Интегрировать HTML5 `MediaRecorder` с нарезкой аудио на чанки по 4 секунды (или с использованием легковесной JS-библиотеки Voice Activity Detection для отправки аудио только когда собеседник замолчал).
*   **Задача 3:** Подключить нативные вибрации (`TelegramSDK.triggerHaptic('medium')`) при обновлении карточек.
*   **Задача 4:** Настроить кнопку экстренной помощи «Помоги сформулировать» (пользователь наговаривает на русском ➡️ ИИ выдает идеальный английский перевод).
