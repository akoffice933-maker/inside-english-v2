# Руководство по превращению Next.js в нативное iOS-приложение и публикации в App Store

Превращение веб-приложения **Inside English v2.0** в полноценное нативное приложение для iPhone и его публикация в **Apple App Store** — это абсолютно реальная задача. 

Наилучшим, самым быстрым и экономически эффективным технологическим стеком для этого является **CapacitorJS (от Ionic)**. Он позволяет обернуть наш готовый проект на Next.js, Tailwind CSS и Zustand в нативный контейнер iOS (Swift/WKWebView), предоставляя прямой доступ к нативному API устройства (звук, пуши, биометрия, покупки).

Ниже представлена пошаговая дорожная карта и разбор критических правил Apple, без соблюдения которых приложение не пройдет модерацию.

---

## 🛠️ Шаг 1. Настройка Next.js для работы с CapacitorJS

Поскольку Capacitor компилирует проект в статическое клиентское приложение (SPA), нам нужно настроить Next.js на генерацию статического экспорта (`next export`).

1. Измените файл конфигурации `next.config.js` в корне проекта:
   ```javascript
   /** @type {import('next').NextConfig} */
   const nextConfig = {
     output: 'export', // Включает генерацию статических HTML/CSS/JS файлов
     images: {
       unoptimized: true, // Локальный рендеринг картинок в iOS WebView
     },
   };
   module.exports = nextConfig;
   ```
2. Установите зависимости Capacitor:
   ```bash
   npm install @capacitor/core @capacitor/cli
   ```
3. Инициализируйте проект Capacitor (конфигурационный файл `capacitor.config.json` уже создан в вашем репозитории):
   ```bash
   npx cap init "Inside English" "com.inside.english" --web-dir=out
   ```
4. Установите платформу iOS и добавьте её в проект:
   ```bash
   npm install @capacitor/ios
   npx cap add ios
   ```
5. Каждый раз при обновлении веб-кода выполняйте сборку и синхронизацию с Xcode:
   ```bash
   npm run build # Генерирует статическую папку /out
   npx cap sync  # Копирует код в нативную папку iOS и обновляет плагины
   ```

## 🚨 Шаг 2. Прохождение модерации Apple: Правила, которые нельзя нарушать

Apple очень строго модерирует приложения. Вот 3 главных правила, из-за которых отклоняют 90% веб-оберток:

### 1. Встроенные покупки (Apple In-App Purchases) — Гайдлайн 3.1.1
*   **Правило:** Если в приложении продается цифровой контент (премиум-аудио, подписка на курсы, отключение рекламы), вы **обязаны** использовать исключительно нативную систему покупок Apple (StoreKit).
*   **Штраф за нарушение:** Если модераторы найдут в iOS-приложении оплату через Stripe, ЮKassa, крипту или просто ссылку на сайт для покупки подписки — **приложение будет мгновенно отклонено**.
*   **Решение:** Интегрируйте плагин **RevenueCat SDK для Capacitor** (`@revenuecat/purchases-capacitor`). Он связывает подписки в App Store с вашей базой данных Supabase за 1 день, избавляя вас от написания сложного нативного кода работы с транзакциями Apple.

### 2. Минимальная функциональность (Minimum Functionality) — Гайдлайн 4.2
*   **Правило:** Apple не пропускает приложения, которые являются просто «сайтом в обертке» (WebView-only). Приложение должно давать уникальный «нативный» опыт.
*   **Решение:**
    *   Интегрируйте нативные пуш-уведомления (через Firebase или OneSignal).
    *   Реализуйте работу в оффлайне (наш Service Worker и кэширование в `sw.js` идеально закрывают это требование!).
    *   Добавьте нативные тактильные отклики (Haptic Feedback) при нажатии кнопок плеера: `npm install @capacitor/haptics`.

### 3. Авторизация через Apple (Sign in with Apple) — Гайдлайн 4.8
*   **Правило:** Если в вашем приложении есть любой социальный вход (Google, Facebook, VK), вы **обязаны** предложить вход через Apple (Sign in with Apple).
*   **Решение:** Supabase поддерживает Sign in with Apple из коробки. Установите плагин `@capacitor-community/apple-sign-in` для красивой системной кнопки.

## 💳 Шаг 3. Интеграция подписок через RevenueCat

Чтобы не писать сложный код обработки транзакций StoreKit, используйте RevenueCat.

1. Установите плагин:
   ```bash
   npm install @revenuecat/purchases-capacitor
   npx cap sync ios
   ```
2. Инициализируйте покупки при старте приложения (например, в `layout.tsx`):
   ```typescript
   import { Purchases } from '@revenuecat/purchases-capacitor';
   import { useEffect } from 'react';

   useEffect(() => {
     if (typeof window !== 'undefined' && window.location.protocol === 'capacitor:') {
       Purchases.configure({ apiKey: "appl_yourAppleRevenueCatApiKey" });
     }
   }, []);
   ```
3. При успешной покупке RevenueCat автоматически отправляет Webhook в ваш бэкенд (Supabase Edge Function), который мгновенно переводит статус пользователя `is_premium` в `true` в таблице `users`.

## 🏗️ Шаг 4. Xcode, Сборка и публикации через TestFlight

Для сборки нативного iOS-приложения вам **обязательно потребуется компьютер macOS (MacBook, Mac mini, iMac)** с установленной программой Xcode.

### Пошаговый процесс публикации:

1.  **Создание аккаунта разработчика:**
    *   Зарегистрируйтесь в программе [Apple Developer Program](https://developer.apple.com/) (стоимость участия — $99 в год). Регистрация оформляется через приложение Apple Developer на iPhone.
2.  **Открытие проекта в Xcode:**
    *   Выполните в терминале команду:
        ```bash
        npx cap open ios
        ```
    *   Xcode откроет ваш нативный проект автоматически.
3.  **Настройка подписи (Signing & Capabilities):**
    *   В Xcode выберите ваш проект в левой панели, перейдите во вкладку `Signing & Capabilities`.
    *   Включите флажок `Automatically manage signing`.
    *   В поле `Team` выберите ваш созданный Apple Developer аккаунт.
    *   Укажите Bundle Identifier (например, `com.inside.english`).
4.  **Создание архива (Archive):**
    *   В верхнем меню Xcode выберите устройство: `Any iOS Device (arm64)`.
    *   Перейдите в меню `Product` -> `Archive`. Xcode скомпилирует приложение в единый бинарный файл.
5.  **Отправка в App Store Connect:**
    *   После завершения сборки откроется окно `Organizer`. Нажмите синюю кнопку `Distribute App`.
    *   Выберите `App Store Connect` -> `Upload` и следуйте подсказкам. Xcode загрузит ваше приложение на сервера Apple.
6.  **Бета-тестирование в TestFlight:**
    *   Зайдите на сайт [App Store Connect](https://appstoreconnect.apple.com/).
    *   Перейдите в раздел вашего приложения ➡️ вкладка **TestFlight**.
    *   Добавьте внутреннюю группу тестировщиков (вас и вашу команду). Вы сможете установить приложение на свои iPhone через официальное приложение TestFlight без прохождения строгой модерации!
7.  **Отправка на публикацию:**
    *   Заполните метаданные приложения (скриншоты для iPhone 6.5" и 6.7" дюймов, описание, ключевые слова, ссылку на политику конфиденциальности).
    *   Нажмите кнопку **Отправить на проверку (Submit for Review)**. Модерация Apple обычно занимает от 24 до 48 часов.

Использование **Next.js + CapacitorJS** позволяет вам сохранить 100% логики и стилей, которые мы уже спроектировали, и запустить приложение в App Store в кратчайшие сроки!
