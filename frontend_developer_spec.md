# ТЗ: Разработка клиентской части (Frontend) веб-приложения Inside English v2.0
**Целевая аудитория документа:** Senior Frontend Developer / Lead React Developer  
**Стек проекта:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Zustand, Framer Motion, CapacitorJS v5, Telegram WebApp SDK.

---

## 1. ВВЕДЕНИЕ И СТРУКТУРА ПРИЛОЖЕНИЯ

Inside English v2.0 — это премиальное кросс-платформенное приложение для изучения английского через состояние расслабления и осознанности. Оно должно собираться под три платформы из единой кодовой базы:
1.  **Web PWA** (с поддержкой полноценного оффлайн-кэширования).
2.  **iOS App** (нативная мобильная сборка через CapacitorJS для публикации в App Store).
3.  **Telegram Mini App (TMA)** (запуск внутри Webview мессенджера Telegram).

### 📁 Структура директорий проекта (App Router):
Разработчик обязан строго следовать следующей архитектуре каталогов:

## 2. ГЛОБАЛЬНЫЙ ДИЗАЙН-КОД И СТИЛИЗАЦИЯ (Tailwind CSS)

Интерфейс должен обладать премиальным, визуально «дорогим» видом (уровень Linear, Vercel, Arc Browser).

### 2.1. Цветовая палитра и темы:
*   **Фон (Background):** `#0D0D14` (глубокий темно-фиолетовый, снижающий утомляемость глаз). Чисто черный `#000000` запрещен.
*   **Карточки (Glassmorphism):** Полупрозрачный фон `#1A1A2E` с прозрачностью `45%`, размытием бэкдропа в `16px` и тонкой белой границей (`border-white/5`).
*   **Градиенты (Primary Glow):** Перелив от насыщенного фиолетового `#6C3CE1` к теплому малиновому `#E94057`.
*   **Текст:** Основной — `#FFFFFF` (сверхконтрастный), вторичный — `#A0A0B0` (пастельный светло-серый).
*   **Акцент подсветки английских слов:** Фиолетовый `#7B61FF`.

### 2.2. CSS-эффекты и анимации (реализованы в `app/globals.css`):
Разработчик обязан использовать готовые утилитарные классы:
*   `.text-glow-purple` — неоновое фиолетовое свечение для подсветки активных английских слов.
*   `.text-glow-pink` — розовое неоновое свечение для акцентов и ошибок.
*   `.glass-panel` — готовый класс для матовых стекол.
*   `.animate-ambient-1`, `.animate-ambient-2` — фоновые размытые круги, совершающие волнообразные медленные движения по экрану.

## 3. ГЛОБАЛЬНЫЙ ЗВУКОВОЙ ПЛЕЕР И СОСТОЯНИЕ (Zustand + HTML5 Audio)

Плеер должен работать бесшовно при переходах между страницами приложения. Стейт вынесен в Zustand (`usePlayerStore.ts`), а нативный экземпляр `new Audio()` инкапсулирован на глобальном уровне.

### 3.1. Троттлинг синхронизации прогресса с сервером:
**КРИТИЧЕСКОЕ ТРЕБОВАНИЕ:** Чтобы не перегружать сервер частыми запросами, плеер обязан отправлять POST-запрос на `/api/tracks/[id]/progress` по следующим правилам:
1.  Каждые **10 секунд** активного непрерывного воспроизведения.
2.  В момент нажатия пользователем на кнопку **Пауза** (`pause()`).
3.  В момент полного **завершения** трека (событие `ended`).

### 3.2. Логика подсветки текста по таймкодам (Lyrics Sync):
Плеер принимает массив токенов `tokens`:
```typescript
interface Token {
  id: number;
  start: number;
  end: number;
  russian: string;
  english: string;
  mixed: string;
}
```
Фронтенд должен рендерить строки, динамически сравнивая `currentTime` аудио-файла с границами `start` и `end`:
*   `currentTime < token.start` ➡️ Будущий текст: `opacity: 0.1` (полупрозрачный).
*   `currentTime >= token.start && currentTime <= token.end` ➡️ Текущая активная фраза: `opacity: 1`, цвет белый, применяется класс свечения `.text-glow-purple`, масштаб `scale(1.02)`.
*   `currentTime > token.end` ➡️ Прочитанная фраза: `opacity: 0.4` (приглушенная).

### 3.3. Трехрежимный переключатель языка (Language Switcher):
Внизу плеера должна располагаться переключалка режимов. Переключение должно происходить мгновенно без перезагрузки аудио:
*   `Русский` ➡️ Отображается `token.russian`.
*   `Смешанный` ➡️ Отображается `token.mixed` (содержит HTML-вставки `<span class="text-[#7B61FF] font-medium">` для выделения английских слов).
*   `English Only` ➡️ Отображается `token.english`.

## 4. ПРЕМИАЛЬНАЯ СИСТЕМА АНИМАЦИЙ (Framer Motion)

Все интерактивные элементы должны подчиняться законам физики упругих тел (Spring Physics). Линейные тайминги запрещены.

### 4.1. Пресеты физики (Spring Constants):
Разработчик должен импортировать готовые конфигурации из `lib/animations.ts`:
*   `gentle` (`stiffness: 150, damping: 20`) — для обычных появлений (модалки, карточки).
*   `bouncy` (`stiffness: 400, damping: 25`) — для сочных отскоков кнопок.
*   `slow` (`stiffness: 100, damping: 20`) — для тяжелых фоновых элементов.
*   `snappy` (`stiffness: 500, damping: 35`) — для микро-реакций (чекбоксы).

### 4.2. Анимация 3D-переворота карт (Flashcard Flip):
Карточка слова перелистывается по тапу:
*   Использовать CSS-свойства `perspective: 1000px` на обертке и `backface-visibility: hidden` на сторонах.
*   Внутренний контейнер анимируется по оси Y: `rotateY: isFlipped ? 180 : 0` с использованием мягкой пружины (`stiffness: 200, damping: 25`).

### 4.3. Анимация валидации ответов в Quiz:
*   **Правильный ответ:** Делается упругий «пружинящий» пульс по шкале `scale: [1, 1.04, 1]`, цвет границы плавно перетекает в зеленый.
*   **Неправильный ответ:** Быстрое затухающее покачивание по оси X (Shake-эффект): `x: [0, -8, 8, -6, 6, -4, 4, 0]`, цвет заливки плавно перетекает в красный.

### 4.4. Доступность (Accessibility - `prefers-reduced-motion`):
**ОБЯЗАТЕЛЬНОЕ ТРЕБОВАНИЕ (Гарантия качества):**  
Разработчик обязан использовать хук `useReducedMotion()` из `framer-motion`. Если в ОС пользователя включена настройка «Уменьшение движения»:
*   Все пружины, тряски и 3D-перевороты должны быть отключены.
*   Анимации заменяются на обычное появление (fade-in) длительностью `150ms`.

## 5. МУЛЬТИПЛАТФОРМЕННЫЕ ИНТЕГРАЦИИ

### 5.1. Поддержка оффлайн-аудио на iOS (Service Worker Range Requests):
Чтобы плеер работал оффлайн на iPhone (iOS Safari), кастомный Service Worker `public/sw.js` должен:
1.  Перехватывать входящие запросы на `.mp3` файлы.
2.  Если файл найден в кэше, считывать его в `ArrayBuffer`.
3.  Парсить заголовок запроса `Range: bytes=start-end`.
4.  С помощью метода `.slice(start, end)` нарезать буфер и отдавать ответ со статусом **`206 Partial Content`** и правильным заголовком `Content-Range`.

### 5.2. Интеграция с Telegram Mini App SDK:
Интеграция вынесена в обертку `lib/telegram.ts`. При запуске внутри Telegram фронтенд должен:
1.  Уведомить Telegram о готовности (`ready()`) и немедленно развернуть окно во всю высоту (`expand()`).
2.  Синхронизировать имя пользователя (`getUser().first_name`).
3.  **Haptic Feedback:** Применять легкие нативные вибрации (`TelegramSDK.triggerHaptic('light')`) при:
    *   Кликах по кнопкам состояний на дашборде.
    *   Перевороте 3D-карточки слова.
    *   Нажатии кнопок Play/Pause в плеере.
    *   Отправке голоса в Shadowing.
    *   Выдаче правильного/неправильного ответа в Quiz (`success` / `error`).

- [ ] Настройки `prefers-reduced-motion` полностью обрабатываются на уровне интерфейса.
