# Архитектура и конвейер генерации аудио-треков Inside English v2.0
**Роль:** Chief Technology Officer (CTO) / Chief AI Architect  

Для запуска и масштабирования проекта Inside English v2.0 ручная запись каждого трека живыми дикторами в студии экономически нецелесообразна (особенно для динамических аффирмаций ИИ-Коуча). Нам необходим **автоматизированный конвейер генерации аудио-треков премиального качества** (аудио-Медитаций и ГипноТреков).

Ниже представлена детальнейшая архитектурная схема генерации, инновационный метод **клиентского сведения звука (Web Audio API)** и пошаговый план разработки.

---

## 🗺️ 1. Архитектура конвейера генерации (Audio Generation Pipeline)

```
[Генерация текста с таймкодами: GPT-4o]
                  │
                  ▼ (Экспорт чистых английских фраз)
[ИИ-Синтез речи (TTS): ElevenLabs / OpenAI]
                  │
                  ▼ (Формат MP3, битрейт 128 kbps)
[Загрузка в Supabase Storage (Приватный бакет 'audio-tracks')]
                  │
                  ▼ (Формирование signedUrl)
[Сведение звука на клиенте: Web Audio API (Голос + Фоновый Loop)]
```

### Шаг 1. Выбор TTS-провайдера (Синтез речи)
Для Inside English критически важен естественный, «живой» голос с правильным дыханием, интонацией и мягким тембром:
1.  **ElevenLabs API (Премиум-выбор):**  
    Абсолютный лидер рынка. Обладает непревзойденными «шепчущими» и медитативными голосами (модель `eleven_multilingual_v2`, голоса `Bella`, `Rachel` или клонированные кастомные голоса). Идеально подходит для ГипноТреков.
2.  **OpenAI TTS API (`tts-1-hd` / `tts-1`) (Экономичный выбор):**  
    Быстрый, стабильный и полностью совместимый. Голоса **`nova`** и **`shimmer`** обладают очень мягким, сонастраивающим женским тембром, а голос **`alloy`** — нейтральным и чистым. Мы используем этот вариант в качестве основного бэкенд-движка для ежедневных генераций.

## 🎧 2. Инновация Inside: Клиентское сведение через Web Audio API

Вместо того чтобы тратить вычислительные ресурсы сервера на тяжелое сведение голоса с фоновой музыкой (дождь, бинауральные ритмы, лес) через `ffmpeg` на бэкенде:

### Мы сводим звук прямо в браузере пользователя!
Плеер загружает два независимых аудио-потока:
1.  **Голосовой поток:** Сгенерированная ИИ-аффирмация/урок (динамический MP3 из Supabase).
2.  **Фоновый поток (Loop):** Короткий зацикленный файл фонового шума дождя, ветра или космического пэда (статический файл из `/public/audio/ambient_rain.mp3`, который кэшируется в PWA-памяти браузера *навсегда*).

#### Схема Web Audio API микшера в плеере:
```
[Сгенерированный Голос] ──► [ Voice GainNode (Громкость 100%) ] ──┐
                                                                 ├──► [ AudioContext Destination ]
[Фоновый Ambient Loop] ──► [ Ambient GainNode (Громкость 15%) ] ──┘
```

#### Продуктовые преимущества клиентского сведения:
*   **Снижение затрат сервера на 100%:** Бэкенду не нужно рендерить, склеивать и пережимать аудио-файлы.
*   **Уникальный интерактивный UX:** Пользователь в плеере может **вручную регулировать громкость фонового шума** и голоса диктора отдельно друг от друга! (Например, сделать дождь погромче, а голос потише).
*   **Мгновенный старт:** Голос весит мало и загружается моментально, а фоновый пэд уже лежит в оффлайн-кэше телефона.
